# 📊 Marketing Analytics Dashboard – Power BI Project

This repository contains a professional **Power BI dashboard for Marketing Analytics**, designed to track key marketing metrics, measure campaign performance, and support strategic decision-making using visual storytelling and data insights.

---

## 🧠 Objective

To build a **data-driven marketing dashboard** that empowers teams to:
- Evaluate campaign success and marketing ROI
- Understand customer behavior and demographics
- Identify high-performing channels and bottlenecks in the funnel
- Track trends over time for informed decisions

---

## 📁 Files Included
- `MarketingAnalyticsProject.pbix` – Power BI file containing:
  - Cleaned data model
  - Custom visuals and charts
  - Interactive dashboard pages
  - DAX measures and calculated columns

---

## 📊 Dashboards & Features

### 1. 🎯 Campaign Performance Overview
- KPIs: Impressions, Clicks, Conversions, CTR, CPC, CPA, ROI
- Date hierarchy for weekly/monthly performance
- Bar & line charts with drilldowns

### 2. 👥 Customer Segmentation
- Geographic heat maps (region/country/state)
- Age group, gender, acquisition source breakdown
- Slicers for demographic filters

### 3. 🔁 Conversion Funnel
- Step-by-step funnel: Awareness → Interest → Decision → Action
- Drop-off visualization between stages

### 4. 📈 Channel Analysis
- Compare Facebook, Instagram, Email, Google Ads, etc.
- Attribution based on conversions & spend

### 5. 📅 Time-Series Trends
- Performance by week/month
- Seasonal trend detection

---

## 🛠️ Tools & Techniques Used
- **Power BI Desktop**  
- **DAX** – custom measures (CAC, CTR, LTV, etc.)  
- **Power Query** – for transforming raw data  
- **Card visuals, tables, slicers, maps, and KPI indicators**  
- **Interactive navigation** using bookmarks and buttons
